# All-in-One Media Converter & Reader

An all-in-one, high-performance desktop tool designed to convert, optimize, edit, and view photo, video, audio, and document files—all within a single interface.

---

## 🌟 Key Features

### 🖼️ Image Processor
* **Multi-Format Conversion:** Seamless support for a wide range of image formats.
* **Resolution & Aspect Ratio:** Precise controls for scaling, resizing, and aspect ratios.
* **Advanced Compression:** Reduce file size while keeping high visual quality.
* **Watermarking:** Add custom text or image watermarks to your pictures.
* **Batch Processing:** Rename (suffixes/prefixes), resize, and convert hundreds of images simultaneously.

### 🎬 Video Converter & Editor
* **Broad Codec & Format Support:** Convert between MP4, MKV, AVI, MOV, and more.
* **Audio Extraction:** Instantly convert videos into audio formats (MP3, WAV, etc.).
* **Fine-Tuned Quality:** Full control over video bitrate, frame rates (FPS), and resolution.
* **Trimming & Resizing:** Crop, scale, and trim specific video timeframes.
* **Video Watermark:** Overlay logos or text for branding and copyright protection.

### 🎵 Audio Suite
* **Audio Conversion:** Convert seamlessly between major audio formats.
* **Bitrate & Quality Tweaks:** Adjust bitrate, sample rate, and channels.
* **Batch Audio Conversion:** Fast multi-file audio optimization.

### 📄 Document Tools & Built-in Reader
* **Document Conversion:** Quickly format and convert document files.
* **Integrated Reader:** View PDFs and other text documents directly inside the application.
* **Dark Mode & Night Shift:** Native Dark Theme and a blue-light reducing Night Shift mode for comfortable reading in low light.

## 🚀 Getting Started

### Prerequisites
* Windows 10/11, macOS 11+, or Linux
* FFmpeg (Recommended for core audio/video processing)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/all-in-one-media-toolkit.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd all-in-one-media-toolkit
   ```

3. **Install dependencies:**
   ```bash
   # For Node.js / Electron apps:
   npm install

   # For Python apps:
   pip install -r requirements.txt
   ```

4. **Run the application:**
   ```bash
   # For Node.js / Electron apps:
   npm start

   # For Python apps:
   python main.py
   ```

## 📖 Quick Usage Guide

1. **Select a Module:** Pick your tab from the side panel—*Photo, Video, Audio,* or *Document*.
2. **Add Files:** Drag and drop your files or folders into the workspace.
3. **Configure Settings:** Set your target format, resolution, bitrate, watermark, or compression ratio.
4. **Export:** Click **Convert / Process** and select your target output directory.
